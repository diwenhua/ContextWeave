# Zstandard decoder

This target contains the upstream Zstandard 1.5.7 decompression-only amalgamation, generated by running `./create_single_file_decoder.sh` in `build/single_file_libs` of the upstream release. The headers in `include` and `LICENSE` are copied from the same release. Use the BSD license in `LICENSE` for this distribution.

To update, regenerate `zstddeclib.c` from the new upstream release and replace the headers and license from that release together.
